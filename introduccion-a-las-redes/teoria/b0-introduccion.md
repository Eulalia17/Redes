# 🧐 B0-Introducción

## **1: Crear tu Cuenta en GitBook**

GitBook es una plataforma moderna para redactar documentación estructurada. El proceso de registro es gratuito y rápido:

#### Recomendado: GitHub / GitLab SSO

Ideal para estudiantes de perfil técnico. Facilita la sincronización de repositorios de código y flujos _Docs-as-Code_.

#### Alternativa: Google o Correo

Puedes registrarte directamente con tu cuenta de correo institucional del centro educativo o tu cuenta personal de Google.

1. Accede a gitbook.com y haz clic en **"Start for free"**.
2. Selecciona tu método de autenticación preferido (GitHub/Google/Email).
3. Confirma tu perfil e introduce el nombre inicial para tu espacio de trabajo personal.



## 2: Comprender la Estructura Organizativa

Para mantener tus asignaturas o proyectos ordenados, GitBook utiliza una jerarquía de 3 niveles principales:

#### Nivel 1. **Organization (Workspace)**

Espacio global de trabajo. Agrupa a todos los miembros del equipo y la totalidad de tus proyectos.

#### Nivel 2. **Space (Proyecto)**

Contenedor donde redactas las páginas y capítulos de un tema, asignatura o memoria concreta.

#### Nivel 3. **Docs Site (Publicación)**

La web o sitio publicado que finalmente visualizarán los usuarios, compañeros o profesores.
