### PAN | WPAN

Permiten intercambio de datos entre móviles, portátiles.\
Es posible el intercambio de datos por cable, aunque también se usan\
memorias USB.\
La WPAN se basa en técnicas como Bluetooth, Wireless USB, ZigBee o Z-Wave\
Limitada a unos 20m de distancia y de baja velocidad\
Permiten la conexión con redes de mayor tamaño.\
Se utilizan sobre todo en el ámbito del ocio, hobbies, IoT…\
La variante inalámbrica que se basa en el Bluetooth se denomina Piconet.

Los dispositivos deben requerir autenticación antes de permitir que otros dispositivos se&#x20;conecten a ellos. Esto evita que dispositivos no autorizados accedan a la red.\
Para proteger la confidencialidad de la información transmitida entre dispositivos en una PAN,&#x20;se utiliza el cifrado de datos. Bluetooth ofrece opciones de cifrado para proteger las&#x20;comunicaciones.\
Es importante la configuración correcta de los dispositivos: cambiar contraseñas&#x20;predeterminadas, desactivar funciones innecesarias y aplicar actualizaciones de&#x20;seguridad siempre que estén disponibles.\
Mantener los dispositivos actualizados con las últimas versiones de firmware permite&#x20;corregir vulnerabilidades conocidas.\
Puesto que tienen un alcance limitado, es menos probable que un atacante externo acceda a la&#x20;red sin estar físicamente cerca de los dispositivos. Sin embargo, sé precavido en entornos&#x20;públicos.\
Fundamental saber gestionar el acceso a dispositivos. Esto es, autorizar únicamente a los&#x20;dispositivos de confianza para conectarse y revocar el acceso aquellos no deseados.\
Se debe realizar seguimiento de las actividades y mantener registros para ayudar a&#x20;identificar actividad sospechosa o no autorizada.

### MAN - metropolitan area network

Es una red de banda ancha que comunica varias redes LAN en una zona&#x20;geográficamente cercana. Se puede ver como una colección de LAN o CAN dispersas&#x20;en una ciudad.\
Podemos decir que se trata de las sedes de una empresa que se agrupan en una MAN&#x20;por medio de líneas arrendadas.\
Una red de área metropolitana puede transportar voz, datos y señal de televisión por&#x20;cable.\
Recursos públicos o privados de telefonía local, cables de fibra óptica, etc.\
Para una MAN, la red Metro Ethernet supone una técnica especial de transmisión con la&#x20;que se pueden construir redes MEN (Metro Ethernet Network) sobre la base de Carrier&#x20;Ethernet (CE 1.0) o Carrier Ethernet 2.0 (CE 2.0).

El estándar para WMAN es el IEEE 802.16.\
Esta tecnología de WiMAX (Worldwide Interoperability for Microwave Access)&#x20;permite crear las llamadas redes WLAN hotzones, que consisten en varios&#x20;puntos de acceso WLAN interconectados en diferentes localizaciones.\
Las redes WMAN se utilizan para ofrecer a los usuarios una potente conexión&#x20;a Internet en aquellas regiones que carecen de infraestructura para ello,\
Puesto que el DSL, el estándar habitual de transmisión, solo está disponible&#x20;técnicamente donde hay hilos de cobre.

3. Aquí la distancia es mayor que la del caso anterior, pero utilizamos una LAN en lugar de una WAN



Tipo de cableado:

Se utilizan varios tipos de cableado y tecnologías de transmisión para conectar los dispositivos. Por&#x20;ejemplo:<br>

* La Fibra óptica como uno de los medios de transmisión más comunes en las WAN debido a la alta  &#x20;velocidad y capacidad de transmitir datos a largas distancias. Utiliza cables de fibra de vidrio o plástico.
* Comúnmente asociado con las redes de TV por cable, el cable coaxial también se utiliza en algunas  &#x20;WAN para la transmisión de datos a través de distancias moderadas. Es más lento que la fibra óptica  &#x20;pero sigue siendo eficiente.
* Las líneas dedicadas son circuitos alquilados de las compañía de telecomunicaciones que  &#x20;proporcionan conexiones confiables y de alta velocidad. Pueden ser conexiones de fibra óptica, cable  \
  coaxial o de otro tipo de cableado, dependiendo de la infraestructura de la compañía.
* La llamada DSL es una tecnología que utiliza el cableado de cobre existente en las líneas telefónicas  &#x20;para proporcionar conexiones de banda ancha a través de distancias cortas a medianas. Existen  \
  variantes como ADSL y VDSL que ofrecen diferentes velocidades y capacidades.
* En áreas remotas o donde no es posible utilizar otros tipos de cableado, las conexiones WAN se  &#x20;realizan vía satélite, para transmitir datos a través de señales de radio.
* Se utilizan conexiones inalámbricas de radiofrecuencia, especialmente en áreas donde la  &#x20;infraestructura de cableado no es práctica. Esto incluye tecnologías como WiMAX y enlaces de  \
  microondas.
* Se pueden utilizar redes celulares para proporcionar conectividad para dispositivos móviles y en áreas  &#x20;donde las redes fijas son limitadas o inexistentes.

WAN privada | WAN pública:

PRIVADAS:

Brindan servicio a una única empresa&#x20;en una conexión de red dedicada para&#x20;ella.\
Proporcionan ancho de banda&#x20;garantizado, ya que todo el ancho de\
banda soportado por el medio está&#x20;dedicado a un único cliente.\
Seguridad, puesto que esa conexión&#x20;se aísla del resto de las redes, y no&#x20;comparte el medio con otros clientes.

&#x20;PÚBLICAS:

El medio de red que utilizan no está dedicado a un solo&#x20;cliente; aunque pueden ser conexiones de datos de un&#x20;único proveedor.\
Comparten la conexión con otros clientes.\
Habitualmente se trata de conexiones que permiten el&#x20;acceso a Internet, y desde ella se permite el acceso a&#x20;cualquier equipo que también esté conectado,&#x20;normalmente a través de una conexión VPN.



Topólogica:

Las topologías WAN se&#x20;describen utilizando la&#x20;topología lógica, es decir, la&#x20;conexión virtual entre un&#x20;origen y un destino concreto:

* Punto a punto: Conexión directa entre dos nodos concretos y solo hay un camino posible entre ellos.
* Estrella: Todos los nodos de la conexión se conectan a un concentrador central. Normalmente son delegaciones que  \
  se conectan a una oficina central. El tráfico enviado entre dos delegaciones ha de pasar por el nodo central  \
  de la topología.
* Malla completa y parcial: Conectividad completa entre todos los nodos de la topología. Proporciona mejor tolerancia a fallos. Conectividad entre diferentes enlaces de la topología. Proporciona redundancia de  &#x20;modo similar a la malla completa. Pero, no se conectan todos los nodos entre sí,  &#x20;reduciendo costes.
* Dual homed: Conecta dos enlaces diferentes desde dos routers a un mismo proveedor, lo que  &#x20;permite proporcionar tolerancia a fallos en la conexión WAN.
* Dual multihomed: Conecta dos routers diferentes a dos proveedores de conexión WAN diferentes. Esta  &#x20;opción permite una mejor tolerancia a fallos.

### VPN

Utiliza la infraestructura de una red física para asociar sistemas informáticos de&#x20;manera lógica.\
Lo más común es utilizar Internet como medio de transporte, ya que este permite&#x20;establecer la conexión entre todos los ordenadores a nivel mundial y, al contrario&#x20;de lo que ocurre con las redes MAN o WAN privadas, está disponible de forma&#x20;gratuita.\
La transferencia de datos tiene lugar dentro de un túnel virtual erigido entre un&#x20;cliente VPN y un servidor VPN.\
Si utiliza la red pública como medio de transporte, suelen cifrarse para\
garantizar la confidencialidad de los datos.\
Se emplean para conectar redes LAN en Internet o para hacer posible el acceso&#x20;remoto a una red o a un único ordenador a través de la conexión pública

### Redes de difusión - broadcast

Los paquetes que envía uno de los terminales son&#x20;recibidos por todos los demás. Al recibir un paquete, un&#x20;terminal verifica el campo del destinatario.\
Si el paquete es para el terminal, lo procesa.\
Si es para otro terminal, lo descarta.\
Los sistemas de difusión (broadcast) tienen la posibilidad&#x20;de enviar un paquete de datos a todos los destinos, lo que&#x20;se consigue poniendo un código especial en el campo de&#x20;dirección.

### Conmutación de paquetes

El mensaje se divide en fragmentos\
Cada fragmento o paquete circula por la red hasta su destino

Ventajas:\
• Si hay un error, solo se envía un paquete\
• Mayor rentabilidad de la red\
• Búsqueda del mejor camino

Desventajas:\
• Duplicidad de paquetes\
• Mayor complejidad de nodos intermedios\
• Menor rendimiento si hay sobrecarga
